tablesync copies your Postgres tables to S3. You set a time, and it runs on its own. It reads rows as a stream, so a big table does not fill up your memory. You do not need a server or a workflow tool. One config file is all it takes. It only sends rows that changed since the last run, so each run stays quick. If the network drops, it waits and tries again. You can see what it did and when, so you always know your data is fresh.
