A slow sync usually has one of four causes. First, check your batch size. A small batch means many trips to the database, and each trip costs time. Second, check where your bucket lives. If it is far from your server, every write takes longer. Third, check if someone added an index to the source table. The database has to keep each index up to date, and that slows down reads. Fourth, check if two syncs are running at once. They then fight for the same database connections, and both get slow.
