Installation of tablesync is accomplished via the standard package manager, after which the binary will be available on your PATH. Prior to initiating your first synchronization, it is necessary to author a configuration file that enumerates the connection parameters for your source database alongside the destination bucket specification. Once this configuration has been finalized, the initial synchronization may be triggered manually in order to validate that connectivity has been correctly established. Subsequent executions will occur automatically according to the schedule you have designated. It is generally recommended that practitioners begin with a single table in order to confirm expected behaviour before expanding the configuration to encompass their complete dataset.
