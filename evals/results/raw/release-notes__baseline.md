tablesync 3.0 introduces a substantially revised configuration format that consolidates previously disparate settings into a unified structure. Please be advised that configuration files authored for prior versions will no longer be parsed successfully, and consequently an upgrade cannot be performed without corresponding modifications to your existing configuration. A migration utility has been provided to facilitate this transition; executing it against your legacy file will generate an equivalent representation in the new format. Additionally, this release incorporates improvements to incremental synchronization and remediates a defect wherein exceptionally large tables could intermittently trigger memory exhaustion during the batching phase.
